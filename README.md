# Harpa Cristã por Estrofes

Este repositório contém todos os hinos da Harpa Cristã organizados por frases e estrofes, disponíveis em dois formatos para facilitar o uso.

## 📁 Arquivos Disponíveis

* **`hinos.txt`**: Ideal para leitura direta, cópia rápida ou uso em sistemas de projeção simples.
* **`hinos.json`**: Estruturado por hino, estrofes e refrão. Ideal para desenvolvedores de aplicativos, sites e bots.

## 🎯 Objetivo
Facilitar o uso e a integração das letras da Harpa Cristã para desenvolvedores, igrejas e estudos pessoais.

## 🚀 Como usar
Basta baixar os arquivos diretamente ou clonar o repositório em sua máquina.
